# 云计算课程资料

本目录统一维护两门课程的教学资料。原始PPT及PDF保持原内容，PPT修改由助教按照说明手动完成。

课程采用考勤10%、一次联邦微调综合项目材料70%、项目汇报20%的考核结构，三阶段20／30／20分直接相加，第13教学周一次提交。无服务器计算与量子机器学习两次课由教师或助教演示，学生观看并参与讨论，无操作任务、无提交、无独立评分。
